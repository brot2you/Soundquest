# SOUNDQUEST V5 — The Great Sound Blackout

Prototype pédagogique jouable et autonome pour GitHub Pages. Ouvrir `index.html` ; publier `index.html` et `sonora-city.webp` à la racine du dépôt GitHub Pages.

## Ce qui est jouable
- Carte illustrée avec 5 générateurs et changements d'état persistants.
- Sound Lab : 3 circuits de discrimination phonémique.
- Rhythm Station : séquence interactive de pulsations.
- Echo Tower : 3 décisions d'intonation contextualisées.
- Accent District : 6 comparaisons UK/US avec transcriptions et synthèse vocale système.
- Voice Studio : enregistrement local facultatif et auto-évaluation guidée.
- PhonoCodex : 10 familles de phonologie avec explications et exemples sonores.
- Sauvegarde automatique localStorage et export/import JSON V5.

## Limites importantes
- Prototype, pas couverture exhaustive de toutes les règles ni cours complets 6e–3e ; les règles incluent des tendances, des exceptions et des variétés.
- La synthèse vocale dépend des voix du système et ne garantit pas l'accent IPA indiqué.
- Le microphone demande HTTPS ou localhost ; aucune analyse automatique fiable des phonèmes n'est fournie.
- L'exercice d'intonation utilise des contours modèles simplifiés, pas des règles universelles.
- L'exercice de rythme est une séquence manipulable, pas une analyse acoustique.
- Le décor est une image 2D interactive, pas un moteur 3D. Les contenus de la V3/V4 ne sont pas automatiquement migrés.
- Les enregistrements ne sont pas persistés et ne sont pas exportés.
